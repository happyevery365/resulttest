固定方法
--------
每张原图单独拆成左/中/右/上四张针孔图，yaw=-45/0/+45，pitch=+45，FOV=90。
每次四张一起 forward；传入各自 K，以及同中心、零平移的已知虚拟旋转。
没有构造虚假基线，没有把不同原图的四视图混成同一次推理。
只取 Pi3X local_points 的 Z 通道和 sigmoid(conf)。预测世界点及预测位姿不参与融合。
回原鱼眼后，将 Z 换为径向距离，按置信度×cos²视角×边缘衰减做加权中值。
不拟合每视图尺度、不补洞、不以图像亮度过滤；min-confidence=0。
先保存 fisheye_range.npy，再从此图与原相机射线生成唯一 PLY。

覆盖率分母是标定模型与处理 FOV 内的有效原图像素，不是整个矩形图像。
重叠分歧 = (同一原像素候选距离最大值 - 最小值) / 合并距离，只统计至少两项有效候选。
这是跨视图一致性诊断，不是 GT 深度误差。六次运行未使用真实深度或激光点云作精度评测。
三个原图分辨率对照的输出距离图均为 3264x3264；点数多不等于独立深度细节多。

原图 448/672/896 的预测局部射线相对输入 K 的角误差中位数：0.104 / 0.143 / 1.231 度。
说明更高分辨率并不保证模型更遵从相机条件。896 输入纹理更清楚，但内部几何一致性下降。
这张图建议 672 作为折中；不将这个单例推广为全部数据集最优分辨率。

推理 forward 耗时（未包含预处理、加载、回填；不是受控速度基准）：

验证
----
python -m unittest -v test_fisheye_depth test_fiord_download
16 项 CPU 测试通过。覆盖超180度鱼眼、投影对照、旋转符号、半像素/缩放约定、
解析球面/平面深度、深度边界、NaN、低置信度、加权中值异常值、唯一点云，以及
HTTP Range 提取、忽略范围请求时拒绝下载、字节预算、COLMAP 相机记录读取。

真实输出额外检查：
- 每个有效原图像素对应恰好一个点；像素索引严格递增，无重复。
- 点数等于有效鱼眼距离数，也等于 PLY 头部记录的点数。
- 所有输出点有限；未覆盖/无效鱼眼像素深度是 NaN。
- 点的三维范数等于保存的径向距离，float32 数值误差小于 1e-4。
- 每次实验只有一份 PLY；没有四份点云拼接产物。

局限
----
一张鱼眼产生四个同中心视图，不增加真实视差。深度来自模型学习先验，绝对米制尺度未验证。
“左中右上”不覆盖全鱼眼，下方等区域保持无效。
实际图像本身倒置，保留原相机坐标；“上”是原图像素方向，不是重力方向。
加权中值减少异常值影响，但不能保证没有接缝或几何错误。
下载的图像与所有推理产物仅在本地实验目录中，公开 Git 仓库只提交代码和说明。
